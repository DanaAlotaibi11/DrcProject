# Contributing to VibraFlow

## Branches

- `main`: Stable version only.
- `hardware/<task>`: ESP32 and wiring tasks.
- `software/<task>`: Signal processing and dashboard tasks.
- `docs/<task>`: Documentation and diagrams.

## Workflow

1. Create a branch for the assigned task.
2. Make small and clear changes.
3. Write a short and descriptive commit message.
4. Open a Pull Request.
5. Ask another team member to review the changes before merging them into `main`.

Do not upload large audio recordings directly to the repository. Store them in shared storage and add a link and description inside the `dataset` folder.
